# 각 — Valorant Lineup Library

발로란트 **각귀체 / 각불 / 각리콘** 라인업 영상을 맵·진영·사이트 순서대로 찾아보는 개인용 웹사이트입니다.

**사이트:** https://mmanimalmm.github.io/V1C/ (표시 이름은 '각'이며, GitHub 저장소명/URL은 V1C 그대로 유지합니다.)

## 화면 이용 순서
1. **카테고리** 선택 — 각귀체, 각불, 각리콘
2. **맵** 선택 — 어센트, 로터스, 헤이븐 등
3. **공격 또는 수비** 선택
4. **사이트** 선택 — A, B, C(해당 맵), 미드. 필요한 경우 추가 사이트명도 데이터에서 자동 인식합니다.
5. **각불만 추가 단계:** 설치 위치(예: 메인 / 욕탕 / 배터리 / 안쪽) → 던지는 위치(예: 램프 / CT)
6. **영상 썸네일** 클릭 — 영상이 연결된 경우 큰 팝업에서 재생

라인업·사이트·요원 검색창은 없습니다. 앞 단계 선택을 변경하면 아래 단계 선택은 초기화됩니다.

각불의 경우 `A에서 B설폭.mp4`, `A에서 B설.mp4`, `A에서 B.mp4`처럼 파일명을 정리해 **A = 던지는 위치**, **B = 설치 위치**를 인식합니다. 영상 파일명은 그대로 보관하고 `throwFrom`, `plantAt`, `title`을 별도로 저장하므로 표시 제목을 나중에 바꾸어도 영상 경로와 분류는 유지됩니다.

## 경쟁 로테이션 맵 (V26 액트 6 · 패치 13.09 기준)

맵 선택은 두 영역으로 나뉩니다. **경쟁 로테이션 맵은 항상 펼쳐 보이고, 그 외 맵은 처음에 접혀 있는 드롭다운**입니다. 그 외 맵 제목을 클릭하면 목록이 펼쳐집니다. 어느 영역을 선택해도 **공격/수비 → 사이트 → 영상**으로 이어집니다.

- **경쟁 로테이션 맵 (7개):** 어비스, 바인드, 코로드, 헤이븐, 로터스, 선셋, 서밋
- **그 외 맵 (6개):** 어센트, 스플릿, 브리즈, 아이스박스, 펄, 프랙처

2026-10-13 발로란트 [공식 패치 13.08](https://playvalorant.com/ko-kr/news/game-updates/valorant-patch-notes-13-08/)에서 바인드·코로드 추가, 어센트·스플릿 제외를 발표했고, [13.09 패치](https://playvalorant.com/ko-kr/news/game-updates/valorant-patch-notes-1309/)에서는 맵 로테이션 변경이 발표되지 않았습니다.

> 맵 로테이션은 자동 갱신되지 않습니다. 새 액트에서 변경되면 `index.html`의 `COMPETITIVE_MAPS` 배열을 수정하세요. 그 외 맵은 자동으로 계산됩니다.


## 영상 등록

`data/lineups.json` 파일의 `lineups` 배열에 아래 형식으로 항목을 추가하세요. **현재는 바인드 14개 + 선셋 6개, 총 20개 각불 영상이 등록되어 있습니다.**

```json
{
  "version": 1,
  "updatedAt": "2026-11-04",
  "lineups": [
    {
      "id": "unique-video-id",
      "kind": "ghost",
      "map": "어센트",
      "side": "atk",
      "site": "A",
      "region": "A 메인",
      "title": "선택 사항: 영상 세부 제목",
      "note": "선택 사항: 조준 위치나 사용 팁",
      "video": "https://www.youtube.com/watch?v=VIDEO_ID",
      "thumbnail": "",
      "addedAt": "2026-11-04"
    }
  ]
}
```

위 객체는 작성 형식만 보여주는 **예시**입니다. 실제 YouTube URL과 지역명을 받은 뒤 등록하면 됩니다.

### 필드 안내

- 각불(`molly`)은 `plantAt`(설치 위치), `throwFrom`(던지는 위치)을 따로 설정합니다.
- 예: `램프에서 메인설폭.mp4` → `plantAt: "메인"`, `throwFrom: "램프"`, `title: "램프에서 메인"` (원본 MP4 파일명 변경 없음).


| 필드 | 설명 |
| --- | --- |
| `kind` | `ghost`(각귀체), `molly`(각불), `recon`(각리콘) |
| `map` | 맵 이름 (예: `어센트`) |
| `side` | `atk`(공격), `def`(수비) |
| `site` | `A`, `B`, `C`, `미드` 또는 사용자 지정 위치 |
| `region` | **썸네일 아래 표시할 지역명**. `title`만 있으면 제목을 대신 표시합니다 |
| `video` | YouTube, Vimeo 링크 또는 MP4/WebM 등 직접 재생할 영상 파일 경로/URL |
| `url` | 선택 사항. `video`가 없을 때 대체 영상 링크로 사용 |
| `thumbnail` | 선택 사항. 이미지 주소 또는 `media/*.jpg` 경로. YouTube 영상은 미입력 시 유튜브 썸네일 자동 표시 |
| `title`, `note` | 선택 사항. 화면에 보이는 제목과 설명. 파일명과 무관하게 나중에 수정 가능 |
| `addedAt` | 새 영상 등록일 (`YYYY-MM-DD`). 14일 동안 각 카테고리 및 맵에 작은 `NEW!` 표시 |
| `id` | 항목을 구분하는 고유 문자열 권장 |

- 영상/이미지 파일을 직접 보관할 때는 기존 `각불영상파일/맵_각불/A사이트/`, `B사이트/` 폴더 또는 `media/` 등에 올린 다음 실제 GitHub 경로를 입력하세요.
- 영상 URL이 YouTube/Vimeo이면 큰 팝업 안에서 임베드 재생합니다. 영상 소유자가 외부 재생을 제한했을 때는 원본 링크를 이용해야 합니다.
- 직접 영상 파일을 지정하면 팝업에 브라우저 영상 플레이어가 표시됩니다.
- 링크를 나중에 전달할 때 **카테고리, 맵, 공격/수비, 사이트, 지역명, 영상 링크**를 알려주면 됩니다.

## 신규 영상 NEW! 표시

- 영상 정보에 `addedAt: "2026-11-04"`처럼 등록일을 지정하면 **그 날짜부터 14일간** 해당 유형(각불 등) 및 맵(선셋 등)에 `NEW!`가 표시됩니다.
- 기간이 지나면 자동으로 사라집니다. 추가로 올라온 새 영상은 등록할 때 `addedAt`을 새 날짜로 기록합니다.
- GitHub Desktop에 MP4 파일만 푸시하면 영상이 자동으로 화면에 등록되지는 않습니다. `data/lineups.json`에 제목·위치·영상 경로를 연결해야 보입니다.
